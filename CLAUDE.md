# Memória Persistente (Obsidian)

Ao iniciar qualquer sessão neste projeto:
1. Leia `claude-memory/projects/itravel.md` no vault Obsidian para recuperar o contexto
2. Leia `claude-memory/preferences.md` para preferências do usuário
3. Leia `claude-memory/decisions.md` para decisões técnicas anteriores

Ao encerrar ou quando solicitado a "salvar memória":
1. Atualize `claude-memory/projects/itravel.md` com o resumo da sessão atual
2. Registre novas decisões em `claude-memory/decisions.md`
3. Atualize preferências descobertas em `claude-memory/preferences.md`

Formato das notas de memória: use Markdown com headers, datas e contexto claro.
